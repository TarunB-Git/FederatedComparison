# FedComparison — Quick start

This repository contains the models, dataset preparation, and runners used in the thesis experiments (hierarchical next-action prediction and federated/backbone-head variants). The instructions below cover the minimal files required, how to prepare artifacts, and how to run the full pipeline or individual model variants.

**Required code files**
- **Core code**: [code/pvp_raw_state_models.py](code/pvp_raw_state_models.py) and [code/hier_models.py](code/hier_models.py)
- **Runners / orchestrator**: [code/run_hier_pipeline.py](code/run_hier_pipeline.py) and [code/hier_backbone_head_race.py](code/hier_backbone_head_race.py)
- **Dataset prep**: [code/prepare.py](code/prepare.py) and [code/hierarchy.py](code/hierarchy.py)
- **Per-paradigm scripts (optional but useful)**: [code/hier_centralized.py](code/hier_centralized.py), [code/hier_fedavg.py](code/hier_fedavg.py), [code/hier_fedprox.py](code/hier_fedprox.py)
- **Utilities**: [code/hier_common.py](code/hier_common.py), [code/hier_metrics.py](code/hier_metrics.py), [code/hier_compare.py](code/hier_compare.py)

**Runtime-produced artifacts**
- `runs/...` — training runs, checkpoints, `final_test.json`, `cross_run_results.csv`.
- `artifacts/` or the `--dataset-dir` you provide — processed dataset files (created by `prepare.py` if you choose `--auto-prepare`).

**Setup (Python environment)**
- Create and activate a virtual environment, then install dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install numpy pandas pyarrow torch scikit-learn matplotlib
```

**Prepare dataset**
- If you already have a prepared dataset directory containing `processed_events.parquet`, `preprocessing.json`, and `action_vocab.json`, skip to Run.
- Otherwise, let the pipeline build artifacts from the raw tournament folders present in the repository (e.g., `2018_IEM_Katowice/` ...). To run preparation manually:

```bash
python code/prepare.py --root . --outdir artifacts --hierarchy-taxonomy legacy8 --split-mode replay
```

This writes `artifacts/processed_events.parquet`, `artifacts/preprocessing.json`, and `artifacts/action_vocab.json`.

**Run the full pipeline (recommended)**
- Run a smoke (fast) end-to-end experiment that will prepare dataset (if needed), run centralized and federated variants, and produce comparison artifacts:

```bash
python code/run_hier_pipeline.py --profile smoke --dataset-dir artifacts --outroot runs/hier_pipeline_smoke
```

Common `run_hier_pipeline.py` flags (most important):
- **--dataset-dir**: path to prepared dataset (if omitted the script uses `artifacts/` or will auto-prepare)
- **--outroot**: where to write run artifacts (defaults to `runs/hier_pipeline_{profile}`)
- **--profile**: `smoke` or `full` (smoke = small quick runs)
- **--modes**: comma list `centralized,fedavg,fedprox,backbone_head` (which paradigms to run)
- **--archs**: comma list `gru,lstm,transformer`
- **--races**: comma list `Prot,Terr,Zerg` or `all`
- **--auto-prepare** / **--skip-prepare**: whether to auto-generate the dataset if missing

**Run a single paradigm / script**
- Centralized (single-race):

```bash
python code/hier_centralized.py --dataset-dir artifacts --outdir runs/centralized_gru_Prot --arch gru --races Prot --profile smoke
```

- FedAvg:

```bash
python code/hier_fedavg.py --dataset-dir artifacts --outdir runs/fedavg_gru_Prot --arch gru --races Prot --profile smoke
```

- FedProx:

```bash
python code/hier_fedprox.py --dataset-dir artifacts --outdir runs/fedprox_gru_Prot --arch gru --races Prot --profile smoke --mu 0.01
```

- Backbone–Head (shared backbone, local heads):

```bash
python code/hier_backbone_head_race.py --dataset-dir artifacts --outroot runs/backbone_head_smoke --profile smoke --arch gru --backbone-races all
```

Key flags across per-paradigm scripts (explanations):
- **--arch / --archs**: encoder type (`gru`, `lstm`, `transformer`). Controls `build_encoder`.
- **--hidden**: encoder hidden dimension (default 256)
- **--layers**: encoder depth (default 2)
- **--dropout**: encoder/dropout fraction
- **--window**: number of previous events to include (e.g., 8)
- **--bs**: batch size
- **--epochs**: local training epochs (centralized) or client epochs (federated)
- **--rounds**: federated rounds (FedAvg/FedProx)
- **--clients-per-round**: number of clients sampled per round (federated)
- **--mu**: FedProx proximal term weight
- **--device**: `cpu` or `cuda`
- **--no-resume**: do not resume from the latest checkpoint

**Outputs and where to look**
- Per-run outputs are under the chosen `--outroot` (or `runs/...`): checkpoints, `final_test.json`, and `cross_run_results.csv`.
- Summary plots can be generated by running `python generate_figures.py` or using scripts in `compare/`.

**Best practices / tips**
- Use `--profile smoke` for fast iteration.
- When experimenting pick one implementation path: prefer the `code/` entrypoints. If you run files from `compare/`, adjust `PYTHONPATH` accordingly.
- If you see import conflicts, remove the alternate `pvp_raw_state_models`/`hier_models` copies from `PYTHONPATH`.
